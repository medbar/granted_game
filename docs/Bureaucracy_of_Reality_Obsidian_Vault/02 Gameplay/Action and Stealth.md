# Action and Stealth

## Базовый жанр

Action / stealth RPG с открытыми пространствами и преследованием.

## Игрок умеет

Базово:
- ходить;
- бегать;
- прятаться;
- взаимодействовать с объектами;
- пользоваться транспортом;
- разговаривать с NPC;
- возможно использовать простое оружие;
- формулировать желания.

## Боевой баланс

Игрок без желаний уязвим.

Цель — не дать обычному вооружению вытеснить центральную механику.

Желания могут использоваться:
- напрямую в бою;
- чтобы изменить окружение;
- чтобы изменить правовой статус объектов;
- чтобы скрыться;
- чтобы снять ограничения;
- чтобы изменить правила преследования.

## Стелс

Желания особенно хорошо должны работать в стелсе:
- «пусть камеры не считают меня человеком»;
- «пусть мой пропуск считается действительным»;
- «пусть эта дверь считается аварийным выходом»;
- «пусть они забудут описание подозреваемого».

Это позволяет решать ситуации не только через урон.
