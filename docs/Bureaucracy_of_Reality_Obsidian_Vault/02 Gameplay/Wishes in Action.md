# Wishes in Action

## Основной ввод

Игрок формулирует желание естественным языком.

Желание описывает желаемое состояние мира, а не конкретную игровую команду.

## Роль дьявола

[[04 Characters/Devil Lawyer|Дьявол]] переводит запрос игрока в юридическую стратегию.

Рабочая модель:

1. Игрок формулирует желание.
2. Дьявол ищет кратчайшее основание среди действующих правил и прецедентов.
3. Если основание очевидно — действие проходит быстро.
4. Если есть несколько спорных трактовок — дьявол может предложить 2–3 пути.
5. Если нужен новый прецедент — игрок должен понимать, какое правило потенциально появится в мире.
6. После исполнения дьявол может кратко объяснить, что именно пришлось юридически изменить.

## Важное ограничение

Игрок не должен постоянно собирать аргументацию из карточек статей и дел.

Юридическое участие игрока должно происходить только там, где есть реальный стратегический выбор.
