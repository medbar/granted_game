# Main Premise

Обычный клерк случайно или намеренно становится клиентом дьявольского адвоката.

Контракт даёт ему доступ к невозможному: любое желание может быть превращено в официальное изменение реальности, если для него удастся найти юридическое основание.

Но сам выход игрока из предписанной жизни делает его нарушением.

Бюрократия начинает его искать.

Игрок:
- выживает;
- узнаёт устройство мира;
- пользуется желаниями;
- создаёт новые прецеденты;
- постепенно понимает, что его адвокат использует каждое дело для собственного проекта.
